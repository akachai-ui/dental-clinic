# 🦷 Smile Clinic - Luxury Digital Dental Clinic Web Application

A modern, high-converting, luxury demo website and patient booking platform for **Smile Clinic**, built with **Next.js 14**, **TypeScript**, and **Tailwind CSS**.

---

## ✨ Features

- **Luxury Navy-Gold Design System**: Tailored for high-end aesthetic dental clinics (Invisalign, Veneers, Digital Implants).
- **Full-Bleed Visual Hero**: Cinematic 8K photography optimized for high conversion.
- **Mobile-First Touch Carousels**: Swipeable horizontal carousels on smartphones for services, promotions, and reviews.
- **Visual Services Showcase**: 6 core specialized treatments with photorealistic medical imagery.
- **Interactive 0% Installment Calculator**: 10-month payment simulator with instant monthly calculation.
- **Google Maps Reviews Hub**: Live 4.9/5.0 rating overview with verified Local Guide reviews.
- **Comprehensive Transit Badges**: Direct access icons for BTS, MRT, Bus, Boat, Motorbike, and VIP Parking.
- **Online Appointment Booking System**: 4-step interactive booking modal with instant confirmation slip generator.
- **Full-Screen Clinical Safety Banner**: Showcasing Class-B CSSD 100% sterilization standards.

---

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/akachai-ui/dental-clinic.git
cd dental-clinic
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
